# EDU Apps Plus SEO rollout

This branch adds the first search-engine optimisation foundation for EDU Apps Plus.

Included:
- commercial site metadata and structured data
- robots.txt generation
- sitemap.xml generation
- custom app development landing page
- education app development landing page
- small business app development landing page
- app idea landing page
- stronger homepage search intent and internal linking
- improved enquiry-page metadata and service navigation

After deployment:
1. Verify `https://www.eduappsplus.com.au/robots.txt` and `https://www.eduappsplus.com.au/sitemap.xml`.
2. Add the domain to Google Search Console and submit `/sitemap.xml`.
3. Add the domain to Bing Webmaster Tools and submit the same sitemap.
4. Monitor indexed pages and search queries before making further keyword/content changes.
